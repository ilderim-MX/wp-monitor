# Plugin WP Monitor

Instala la carpeta `monitor-status/` como plugin (o sube `monitor-status-1.1.0.zip`).
En **Ajustes → WP Monitor** pon el **servidor** (sin https://) y el **código** que te dieron en el panel, y dale **Guardar y conectar**.
El plugin envía su reporte cada 6 horas. No expone ningún endpoint en el sitio.
